# Taskify — Task Manager with AI Assistant

Веб-приложение для управления задачами с интегрированным LLM-ассистентом на базе Groq API.

## Реализованный функционал

- **CRUD задач** — создание, просмотр, редактирование, удаление
- **Фильтрация и поиск** — по статусу, приоритету, полнотекстовый поиск
- **Виды** — Все задачи / Сегодня / Ближайшие 7 дней / Срочные
- **AI: умная категоризация** — предлагает тег/категорию по названию и описанию
- **AI: декомпозиция** — разбивает сложную задачу на подзадачи
- **AI: приоритет** — рекомендует приоритет на основе описания и срока
- **AI: сводка нагрузки** — естественно-языковой анализ текущих задач

## Стек

| Слой | Технология |
|---|---|
| Frontend + Backend | Next.js 16 (App Router) |
| База данных | SQLite через Prisma 5 |
| LLM | Groq API (`llama-3.3-70b-versatile`) |
| Стили | Tailwind CSS |
| Язык | TypeScript |

## Настройка и запуск

### 1. Клонирование репозитория

```bash
git clone <repo-url>
cd task-manager
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Переменные окружения

Создайте файл `.env` в корне проекта:

```env
DATABASE_URL="file:./dev.db"
GROQ_API_KEY="ваш_ключ"
```

Ключ Groq API бесплатно доступен на [console.groq.com](https://console.groq.com).

### 4. Инициализация базы данных

```bash
npx prisma db push
```

### 5. Запуск

```bash
npm run dev
```

Приложение доступно на [http://localhost:3000](http://localhost:3000).

## Архитектурные решения

- **Разделение ответственности**: бизнес-логика в API routes, UI — в компонентах, доступ к БД — через Prisma-слой в `lib/prisma.ts`.
- **RESTful API**: стандартные HTTP-методы (GET, POST, PUT, DELETE), корректные статус-коды (200, 201, 400, 404, 500), структурированные ошибки.
- **Фильтрация на сервере**: все параметры фильтрации передаются в запросы к БД, а не обрабатываются на клиенте.
- **Singleton Prisma Client**: предотвращает исчерпание пула соединений при hot-reload в dev-режиме.
- **Prompt Engineering**: системные промпты с явными ролями, требованием JSON-вывода и few-shot примерами там, где это улучшает качество ответа.

## Известные ограничения

- Файловая БД SQLite не подходит для многопользовательского продакшена — при необходимости схема Prisma легко переключается на PostgreSQL.
- LLM-запросы не кешируются — при высокой нагрузке стоит добавить Redis-кеш или очередь.
- Аутентификация не реализована (не входила в ТЗ).
